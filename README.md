# Bambu HandWrite

**Bambu HandWrite 3.4** — экспериментальный браузерный редактор рукописного текста и генератор G-code для пробного использования с Bambu Lab A1 и держателем ручки.

> ⚠️ Это независимый экспериментальный проект, не связанный официально с Bambu Lab. Перед запуском G-code обязательно прочитайте [правила безопасности](docs/SAFETY.md). Физическая работа на принтере этой версией не подтверждена.

## Возможности

- Рукописный текст на странице в клетку, линейку или на чистом листе A4.
- Русский и английский текст, несколько шрифтовых профилей.
- Просмотр и диагностика траекторий.
- Экспорт SVG и PNG.
- Генерация G-code прямо в браузере.
- Две остановки в сценарии подготовки: первая ручная, вторая автоматическая (по умолчанию 130 секунд).
- Автосохранение и резервная копия настроек в JSON.
- Мобильный интерфейс.

## Запуск

Откройте `index.html` в современном браузере. Приложение не требует собственного сервера или сборки. Некоторые дополнительные шрифты загружаются из Google Fonts; без интернета используется системный курсив.

## Поддержка принтеров

Текущая экспериментальная конфигурация рассчитана на **Bambu Lab A1**. Другие модели пока не объявляются совместимыми. Предложить поддержку другой модели можно через **Issues → Support another Bambu Lab printer**. Каждый новый профиль должен быть отдельно адаптирован и проверен на соответствующем принтере.

## Проверки и безопасность

- Автоматическая проверка: `node scripts/validate.mjs`.
- Перед использованием изучите [SAFETY.md](docs/SAFETY.md).
- Отчёт проверок: [TEST_REPORT.md](TEST_REPORT.md).
- Реальная печать на Bambu Lab A1, физический зазор и совместимость с прошивками не подтверждены.
