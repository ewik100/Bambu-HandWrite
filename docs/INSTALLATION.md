# Установка и запуск

## Обычному пользователю

1. Скачайте `index.html` из корня репозитория (кнопка Download на странице файла GitHub).
2. Сохраните файл на компьютер или телефон.
3. Откройте его браузером Chrome, Edge, Firefox или Safari.
4. Разрешите браузеру открывать локальные HTML-файлы, если он спросит.

Приложение не устанавливается как отдельная программа и не требует сервера. Для интерфейса не нужен Node.js.

## Запуск с GitHub Pages

Когда Pages будет включён для репозитория, можно открывать опубликованный адрес вместо локального файла. Владелец репозитория должен открыть **Settings → Pages**, выбрать **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохранить. Главная страница должна называться `index.html`.

Адрес GitHub Pages обычно имеет вид `https://<username>.github.io/<repository>/`. Не считайте сайт опубликованным, пока GitHub не покажет готовый Pages URL в настройках.

## Разработчику

- Node.js 20+ нужен только для `node scripts/validate.mjs`.
- Приложение — один самостоятельный HTML-файл, отдельная сборка не нужна.
- Внешняя необязательная зависимость — таблица стилей Google Fonts. Без неё будет системный шрифт.
- Перед публикацией изменения запускайте локальную проверку и просматривайте приложение в обычном браузере.
