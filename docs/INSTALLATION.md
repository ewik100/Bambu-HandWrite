# Установка и запуск

## Открыть актуальную версию

- Веб-приложение: https://ewik100.github.io/Bambu-HandWrite/ — актуальная версия из ветки `main`.
- Отдельный файл: [Bambu-HandWrite-5.8.0.html](../releases/Bambu-HandWrite-5.8.0.html).
- Исходный файл: [index.html](../index.html).

Приложение работает в современном браузере. Установка, сервер и сборка для обычного использования не нужны. Для внешних шрифтов требуется интернет; встроенный Pecita доступен локально.

## Локальный запуск

1. Скачайте `index.html` или отдельный файл версии из папки `releases`.
2. Сохраните HTML-файл на компьютер или телефон.
3. Откройте его в Chrome, Edge, Firefox или Safari.
4. Если браузер ограничивает локальные файлы, используйте веб-версию GitHub Pages.

## Разработчику

- Node.js 20+ используется для скриптов проверки в `scripts/`.
- Основное приложение — самостоятельный HTML-файл; отдельная сборка не нужна.
- Перед публикацией проверяйте HTML/JavaScript, тесты маршрутов и работу в браузере.
- Автоматические проверки не заменяют просмотр G-code и физическую проверку на целевом принтере.
