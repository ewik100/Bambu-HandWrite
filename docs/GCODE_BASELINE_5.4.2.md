# G-code baseline — Bambu HandWrite 5.4.2

Этот документ фиксирует исполняемые команды и порядок, использовавшиеся в версии 5.4.2. Он нужен как контрольная точка для последующих изменений раскладки бумаги.

## Разрешённые исполняемые команды

В 5.4.2 генератор и предполётная проверка разрешали только эти семейства команд:

- `G0` — быстрое перемещение по XY без письма, парковка и подвод пера.
- `G1` — перемещение пера по XY и изменение координаты Z (подъём/опускание).
- `G21` — миллиметровые единицы.
- `G28` — homing всех осей после ручной паузы 1.
- `G90` — абсолютные координаты.
- `M73` — два маркера прогресса: начало и завершение.
- `M400` — синхронизация, ручная пауза и заданные временные остановки.

Других исполняемых команд в маршруте пера 5.4.2 нет.

## Старт — фиксированный порядок

```gcode
M73 P0 R1
G21 ; metric units
G90 ; absolute positioning
M400 U1 ; PAUSE 1
G28 ; home all axes
G1 Z{safe} F1200 ; safe height above plate
M400
G0 X{pageLeft} Y{pageTop} F2000 ; pause above paper top-left
M400
M400 S{pause2Seconds} ; SECOND STOP
```

`{safe}` — безопасная высота Z, `{pageLeft}` и `{pageTop}` — машинные координаты верхнего левого угла страницы. Время второй остановки задаётся пользователем.

## Контур защитного листа и 50-секундная укладка

```gcode
G1 Z{travel} F1200 ; pen up before drawing the page outline
G0 X{left} Y{top} F1900 ; outline start on protective A4
G1 Z{write} F1200 ; draw outline on protective A4
G1 X{right} Y{top} F1250 ; outline top edge
G1 X{right} Y{bottom} F1250 ; outline right edge
G1 X{left} Y{bottom} F1250 ; outline bottom edge
G1 X{left} Y{top} F1250 ; close outline
G1 Z{safe} F1200 ; lift before sheet placement
G0 X{placementParkX} Y{placementParkY} F2000 ; move clear of page
M400
M400 S50 ; 50-second placement window
G1 Z{travel} F1200 ; pen-up travel after placement
```

Контур всегда остаётся прямоугольником полного выбранного формата бумаги. Сторона красного поля не меняет точку второй остановки, физический прямоугольник контура, точку парковки или длительность укладки.

## Повторяющийся шаблон штриха текста

Для каждого отдельного штриха:

```gcode
G1 Z{travel} F1200
G0 X{strokeStartX} Y{strokeStartY} F{rapidFeed}
G1 Z{write} F1200
G1 X{strokePointX} Y{strokePointY} F{drawFeed}
...
G1 Z{travel} F1200
```

Координаты XY каждого штриха вычисляются из центральных линий букв. При выборе перевёрнутой стороны страницы меняются только XY координаты текста, поскольку меняются границы его раскладки. Командные семейства, скорости шаблона, высоты Z и системная последовательность остаются прежними.

## Завершение — фиксированный порядок

```gcode
G1 Z{safe} F1200 ; final safe lift
G0 X128.000 Y246.000 F2000 ; park/present bed
M73 P100 R0
M400
```

## Что запрещено добавлять без отдельной проверки A1

- `M83` — режим относительной экструзии, в pen-plotter маршруте не нужен.
- `M400 P...` — не используется; в проекте отмечено как проблемная команда для проверенного короткого теста A1.
- `M104`, `M140`, `M106` — команды нагрева/вентилятора не входят в файл пера.
- Любые другие новые семейства G-code — только после отдельной проверки на A1 и обновления предполётного валидатора.

## Контрольное правило для будущих версий

Перестановка красного поля, расчёт отступов, предпросмотр и раскладка букв могут менять координаты рисующих XY-перемещений. Нельзя менять без отдельной просьбы и тестирования:

1. Старт `M73 P0 R1 → G21 → G90 → M400 U1 → G28`.
2. Вторую автоматическую остановку `M400 S{pause2Seconds}` над верхним левым углом.
3. Подъём пера перед контуром.
4. Четыре стороны полного прямоугольного контура на защитном A4.
5. Подъём и парковку за пределами страницы перед `M400 S50`.
6. Подъём пера после 50-секундного окна.
7. Финал `G1 Z{safe} → G0 X128.000 Y246.000 → M73 P100 R0 → M400`.
