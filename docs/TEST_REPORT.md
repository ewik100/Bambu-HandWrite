# Отчёт проверок Bambu HandWrite 4.0

Дата сборки пакета: 2026-11-08.

## Выполненные проверки релиза 4.0

- Встроенный JavaScript извлечён из `index.html` и проверен на синтаксические ошибки Node.js.
- Проверено наличие обязательной разметки HTML и одного основного inline-script.
- Проверена уникальность атрибутов `id`.
- Проверено наличие ограничителей координаты Z и пауз/предупреждений в исходном файле.
- Проверены ссылки на локальные документы и структура файлов.

Результаты CI GitHub Actions для версии 4.0: `node scripts/validate.mjs` — 24 проверки пройдены; `node scripts/test-unit.mjs` — 18 модульных проверок пройдены. Дополнительно проверены синтаксис встроенного JavaScript, уникальность HTML id, расчёт целевой высоты строчных букв и координаты сопла при второй остановке. Синтаксис всех YAML-файлов шаблонов GitHub Actions/Issues проверен отдельно с помощью PyYAML.

## Перед первым физическим запуском

- Подберите и закрепите держатель так, чтобы он не задевал раму, кабели, вентиляторы и пластину.
- Измерьте фактический вылет кончика ручки относительно сопла и откалибруйте Z.
- Проверьте положение бумаги, зажимы и свободный проход по всей траектории.
- Выполните короткую контролируемую калибровку и постоянно наблюдайте за принтером.
- Для A1 mini, P1P, P1S, X1 Carbon и других моделей требуется отдельная адаптация координат и команд.

Автоматические проверки подтверждают корректность проверяемых участков исходного кода, но не измеряют механическую конструкцию пользователя и не заменяют индивидуальную настройку.

## Как воспроизвести автоматическую проверку

Из корня репозитория:

```bash
node scripts/validate.mjs
```

Статическая проверка обнаруживает часть ошибок разметки/синтаксиса. Она не заменяет запуск в браузере, анализ G-code и физический тест.
