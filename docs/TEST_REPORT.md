# Отчёт проверок Bambu HandWrite 3.4

Дата сборки пакета: 2026-11-08.

## Выполненные проверки

- Встроенный JavaScript извлечён из `index.html` и проверен на синтаксические ошибки Node.js.
- Проверено наличие обязательной разметки HTML и одного основного inline-script.
- Проверена уникальность атрибутов `id`.
- Проверено наличие ограничителей координаты Z и пауз/предупреждений в исходном файле.
- Проверены ссылки на локальные документы и структура файлов.

Результаты локальной автоматической проверки: `node scripts/validate.mjs` — 24 проверки пройдены; `node scripts/test-unit.mjs` — 14 модульных проверок пройдены. Синтаксис всех YAML-файлов шаблонов GitHub Actions/Issues проверен отдельно с помощью PyYAML.

## Не выполнено

- Не запускался на физическом Bambu Lab A1.
- Не проверялся с конкретным держателем ручки.
- Не подтверждены фактический зазор пера, координаты, свободный проход при homing, парковка и поведение двух пауз.
- Не проверена каждая буква на каждом шрифте и на каждой версии браузера.
- Не подтверждена совместимость с A1 mini, P1P, P1S, X1 Carbon и прочими принтерами.

## Как воспроизвести автоматическую проверку

Из корня репозитория:

```bash
node scripts/validate.mjs
```

Статическая проверка обнаруживает часть ошибок разметки/синтаксиса. Она не заменяет запуск в браузере, анализ G-code и физический тест.
